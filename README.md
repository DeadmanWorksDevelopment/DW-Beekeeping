FIVEM SCRIPT

Bring a complete player-owned beekeeping economy to your FiveM server with Deadman Beekeeping.

Players can capture wild queen bees, build persistent colonies, maintain and upgrade their hives, harvest regional honey, process resources and sell their products for profit.

Features
Supports QBCore and ESX Legacy
Automatic framework detection
Player-owned persistent beehives
Database persistence through server restarts
Capture wild queen bees
Place and relocate owned hives
Hive maturation and honey regeneration
Configurable hive progression tiers
Colony health, feeding and aggression
Interactive harvesting skill checks
Bee smokers reduce sting risks
Regional honey varieties
Honey and beeswax production
Working honey extractor
Supply vendor and honey buyer NPCs
Steal honey or queen bees from other hives
Optional owner theft alerts
Physical hive damage and destruction
Automatic abandoned-hive cleanup
No global hive blips
Server-side validation for important actions
Configurable cash or bank transactions
Base-game props with no custom model pack required
Easy Installation
The resource arrives inside a ready-to-install dw-beekeeping folder.

Drag and drop the folder into your server resources.
Import the included SQL file.
Add the supplied ox_inventory item entries and images.
Add ensure dw-beekeeping after the required resources.
Restart your server and begin beekeeping.
A complete customer installation guide is included.
